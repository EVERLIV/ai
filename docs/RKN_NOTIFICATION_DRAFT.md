## 3. Категории персональных данных

**Отметить:**

- фамилия, имя, отчество  
- номер телефона  
- адрес электронной почты  
- адрес (если пользователь указывает в профиле / объявлении / заявке)  

**В «иные» / доп. поле (если есть):**

```
Сведения из форм заявок и отзывов; данные учётной записи; сведения
об объявлениях; технические данные (IP-адрес, cookie / localStorage,
User-Agent, сведения о браузере и устройстве) в объёме, необходимом
для работы Сервиса и защиты от автоматизированных обращений.
```

**Не отмечать:** специальные категории, биометрия, расовая/национальная принадлежность и т.п. — **не обрабатываются**.

## 4. Категории субъектов персональных данных

**Отметить:**

- пользователи сайта / клиенты (соискатели, собственники, риелторы и иные зарегистрированные пользователи)

Работников — только если реально ведёте кадровые ПДн; для текущего продукта обычно **не отмечают**.

```
Средства криптографической защиты информации, имеющие сертификат
```
